# Теория субстрата git+gate (карта теорем v=i)

Источники: private/papers v=i, прежде всего 1_verification_is_identification
(VII), 6_distance_is_cost (DiC), 3_permanence_is_resistance (PiR),
R_reading_is_order (RiO), E2_solvability_criterion. Ссылки — на §§ бумаг.

## 1. Тождество: git — это V=I для байтов (теорема, не метафора)

VII §0, A11: если ровно один кандидат проходит тест — проверка есть
опознание. Content-addressing git — |S| = 1 ПО ПОСТРОЕНИЮ: у содержимого
один хеш, у ссылки один кандидат. `git fsck` — суд A8.

VII A12 — три запрещённые степени свободы: «mutable test breaks A4;
growing space breaks A7; retractable record breaks A8». Это точный
дизайн-док git: фиксированная хеш-функция (тест неизменен), объект
неизменяем (I3: «Retraction is not prohibited — it is impossible»),
пространство объектов замкнуто хешем. Git выжил, потому что случайно
соблюл все три запрета; gate соблюдает их сознательно.

Словарь соответствий:
| v=i | git | gate |
|---|---|---|
| Σ (финитные структуры) | объекты (blob/tree/commit) | записи мира |
| COMPARE | равенство хешей | лукап судьи |
| G, append-only (I3) | DAG истории | журнал/premises |
| S, пас-сет | объекты, прошедшие fsck | judged-мир |
| encoding (агента) | формат объектов | формы мира (FORMS.md) |
| agent / system (§1 Loop) | писатель / fsck | писатель-кто-угодно / судья |
| REJECT с адресом | «bad object <hash>» | «file:line · A против B» |

## 2. Теоремы, уже доказывающие свойства субстрата

**Недоверенные писатели, любое их число.**
VII Theorem 2 (Safety): PASS → f' = f*, «regardless of how the encoding
was chosen»; «Safety comes from verification, not search». Писатель —
человек, sonnet, кто угодно: гарантия не зависит от генератора (наш AI6).
VII §5.26 SAT6: «L invariant across agents» — два агента над одним
доменом производят одну библиотеку, различие только в порядке вставки.
Содержимое определяется доменом, не агентом. ⇒ «сотни агентов в одной
базе» — не инженерная удача, а теорема.

**Порядок мержей не влияет на правду.**
VII §5.25: «Correctness is order-invariant; efficiency is
order-determined» — порядок раскрытия фактов — единственная динамическая
переменная; все полные обходы приходят в один endpoint. RiO §3 даёт
категорную форму (anamorphism uniqueness). ⇒ мерж-очередь можно
пересортировывать, батчить, распараллеливать — вердикт конечного мира
один; оптимизация очереди — вопрос эффективности, не правды.

**Шардинг доменов.**
VII §5.12 (CO3): T = T₁ ∧ T₂ → проверяются независимо, joint PASS =
component-wise PASS. ⇒ мир на домен, миры судятся порознь, произведение
масштабируется линейно.

**Инкрементальный суд — теперь ТОЧНАЯ теорема.**
VII §5.18 (CA2, CA3) давал потолок (кэш переносим); MiC4 (статья
merge_is_commutation, 95014c7) даёт пол: пересуживается ровно
затронутое — вердикт закона есть функция его носителя (MiC1).
Полный пересуд — честный потолок прототипа, инкрементальный — не
оптимизация, а механизация теоремы.

**Дифф — метрика, отказ — адрес.**
DiC Theorem G2: W(s, t) = |D(s) △ D(t)| и W — метрика на Σ. Дифф двух
миров — расстояние в точном смысле; «меряем только дифф» — измерение
метрики. DiC frontier(s,t) — префикс-минимальные адреса расхождения —
теоретическое имя того, что наши отказы называют адресом. ⇒ цена
изменения, размер PR, «горячесть» записей — величины одной метрики.

**Метрики неподдельны.**
VII §5.20–5.22 + axis alignment: факты пред-существуют (revelation, not
creation — «таблица читается, не хранится» дословно), S монотонно
сжимается, и «saturation (1 − |S|/|F|) is an incorruptible progress
metric — cannot increase without genuine elimination, cannot decrease at
all». I3 — генератор со-ориентации всех осей. ⇒ метрики gate текут из
суда и не накручиваются в принципе.

**Конвергенция и зрелость домена.**
PiR M8 (Ignition): насыщение библиотеки дискретно (|L| = K — порог);
M12 (Convergence): всякая V=I-игра на конечном Σ сходится к неподвижной
точке (L*, G*). ⇒ у домена есть измеримая зрелость: библиотека форм
насыщается, после чего новые задачи решаются лукапом (VII §5.26 SAT4).
Продуктовая метрика «домен закрыт: N форм» — теоремная.

**Информационная цена идентификации — АНАЛОГИЯ, не клейм.**
VII IT1–IT6: идентификация требует log₂|F| бит. Квалификация той
стороны принята: ревью человека — не идентификация f*, перенос
Shannon-границы на «минимальный объём ревью» — питч-натяжка. Держать
как риторическую рамку, в доказательную базу не включать.

**Пол (предел, заявленный теорией).**
VII §5.23: пайплайн не берёт себя на вход (no self-reference); §6:
«Correctness is relative to R(x,y) — if verifier doesn't capture
semantics, f* may not match intent. Agent designs the verifier». Это
PP15: гейт не сертифицирует себя; намерение и двойная согласованная
правка — человеку. Наши W3/«чего не обещаем» — реализация этого пола.

**Потенциал охвата.**
VII Theorem 4 (Universality): для любой конечной детерминированной
задачи существует кодировка с R4. ⇒ вопрос всегда «сделал ли энкодер
задачу конечной», никогда «конечна ли задача по природе» — потолка
доменов нет; цена входа живёт в энкодере (E2: энкодер-регресс решается
двумя этажами, вся сложность там).

## 3. Достройка субстрата — ИСПОЛНЕНО той стороной (95014c7)

Посылка принята и доказана в ядре: статья **Merge Is Commutation
(Record)** — вывод целиком внутренний (запись, закон, носитель, правка;
ни git, ни хеша). Ссылки для нас: **MiC1** локальность (вердикт закона —
функция его носителя, из §5.24), **MiC2** коммутация (независимые правки
сливаются в любом порядке; родитель — DiS «rules over different slots
commute», НЕ §5.25 — тот про порядок чтения), **MiC3** транспорт (слитая
позиция зелёная ⟺ обе части зелёные, вердикты переносятся с целыми
адресами, из §5.12), **MiC4** точный инкрементальный пересуд (кэш давал
потолок §5.18, локальность даёт пол: пересуживается РОВНО затронутое).
§6 — three-way через симметрические разности DiC: мерж безопасен при
ДВУХ пустых пересечениях, overlap — перечислимое множество адресов
(наш frontier).

**Две поправки их формулировки — обязательны для нашей реализации:**
1. **Независимость — ДВА условия, не одно**: (i) изменённые записи
   дизъюнктны — мерж ОПРЕДЕЛЁН; (ii) затронутые законы дизъюнктны
   (закон затронут, если его носитель пересекает изменённое, ВКЛЮЧАЯ
   законы, принесённые самим диффом) — вердикты ПЕРЕНОСИМЫ. Моё
   одноусловное «P(D₁)∩P(D₂)=∅» пропускало записевый конфликт — будущий
   инкрементальный чекер/параллельный мерж строить только по двум.
2. **Родословная**: родитель — DiS, не VII §5.25. Чтить в цепи
   источников.

Статья в латтисе recorded, not pinned (коммутация — о двух траекториях,
латтис траекторию значением оси не принимает; house-паттерн B8b/GD7).

## 3½. Кристаллы и операции множеств (формализация)

Из SAT5 («library unique up to insertion order») следует: у домена под
фиксированной кодировкой существует ОДИН канонический кристалл L* —
объективно, независимо от того, кто и в каком порядке его насыщал.
Отсюда:
- **Два насыщенных кристалла одного домена структурно равны** (различие
  — только порядок вставки).
- **Два ненасыщенных мира — два подмножества L*** ⇒ операции множеств
  корректны и безопасны: union бесконфликтен по построению (Theorem 2:
  у класса правил один f*, он совпадёт у обоих), L_A ∖ L_B — «чему A
  может научить B», |L△L| — дифф зрелости (та же W-метрика DiC G2,
  применённая к библиотекам).
- **Приватность держится по построению**: библиотека — формы и оси, не
  факты; обмен кристаллами не передаёт данных клиента.
- **Кросс-доменные зависимости** — §5.18 (COMPARE context-independent):
  общие структуры (атомы, оси, формы) переносимы между доменами; кэш
  домена A ускоряет домен B ровно на пересечении структур. Поиск
  зависимостей = пересечение кристаллов разных доменов.

Прожито глаголом `gate library`: кристалл клиента (4 формы, 8 осей,
покрытие посевами 4 held / 1 no-gate), кристалл корпуса (7 форм),
разность — Granted+{View,Administer,Delete}: «teachable» вычислен
set-операцией.

## 3¾. Решётка атомов и ось времени (двумерность субстрата) — ПРОЕКЦИЯ

Статус по квалификации той стороны, принят: красивая проекция, не
теорема ядра. Решётка подмножеств L* (SAT5) и монотонность I3 — ядро;
композиция «время × решётка» как единая картина — наша проекция для
продукта и питча. Использовать как язык, не как доказательство.

Из SAT5 миры домена — подмножества канонического L*, и они образуют
решётку в строгом смысле: порядок «A ⊆ B», join = union (безопасен по
Theorem 2 — прожито set-операциями library), meet = пересечение (общее
ядро). Сатурация — подъём к вершине; порог дискретен (PiR M8).

Двумерность: git — ось времени (диахрония), решётка — пространство
состояний (синхрония). Коммит — точка траектории по решётке. По I3
траектория МОНОТОННА ПО АТОМАМ (атомы не удаляются — «retraction is
impossible»), свободна по статусам (live→dead→archived — движение
видимости, не бытия). Мировая линия атома = git log его записи:
история смысла, а не строк.

«Строим и управляем» — оба глагола имеют форму:
- строить = монотонный подъём (import/формы/мосты) — только вверх;
- управлять = записанные законы движения: переходы статусов — тройки
  Slot/From/Into (жанр прожит плейграундом), права перехода — guard,
  обязательность перехода (таск закрыт ⇒ флаг умирает) — гейт связи.
  Жизненный цикл атома — судимый автомат, не диаграмма на вики.

Формула: git хранит движение во времени, gate держит решётку смысла в
каждой его точке; решётка растёт только вверх, видна целиком и
управляется записанными законами.

## 4. Что это меняет в потенциале (следствия карты)

- «Сотни агентов в одной базе» опирается на Th2+SAT6, не на бенч: бенч
  (26k мержей/час) — измерение константы, теорема — отсутствие потолка
  по числу писателей.
- Библиотека форм — общая между клиентами одного домена (SAT5-6: L
  определяется доменом): сетевой эффект без сети — каждый переведённый
  домен обогащает каталог, который у всех один с точностью до порядка.
- Сатурация — продуктовая шкала зрелости: «домен закрыт, N форм,
  дальше — лукап» (M8: порог дискретен, объявляем его честно).
- Метрики gate неподдельны по построению (axis alignment) — можно
  строить на них SLA/аудит, не опасаясь Goodhart-накрутки изнутри.
